FLOW
Browser form -> Cloudflare Pages /api/waitlist -> Email Worker /api/signup -> Brevo

WORKER REQUIRED VARIABLES / SECRETS
BREVO_API_KEY
BREVO_LIST_ID
BREVO_SENDER_EMAIL
BREVO_SENDER_NAME   (optional)
ADMIN_TOKEN

TURNSTILE_SECRET is NOT used and can be deleted from the Worker.

PAGES REQUIRED VARIABLE
EMAIL_WORKER_URL=https://<your-worker>.workers.dev

Content-Type: application/json

{

  "companyWebsite": "",

}
